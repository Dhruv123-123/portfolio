# Working preferences for Claude in this repo

## How to deliver answers (standing rule from Dhruv)

- Keep written text brief: a few sentences, or a short bulleted list. No long prose reports.
- Deliver the substance visually. Default to one of:
  - an interactive HTML artifact (three.js / WebGL when a 3D or spatial view helps),
  - a PowerPoint deck (.pptx) when the content is slide-shaped,
  - another visual format (diagram, chart, dashboard) when it fits better.
- This applies to research, analysis, and explanations, not only to code work.
- Text in chat should summarise and point to the visual, not duplicate it.
