## Blackbox

`/blackbox` (also a window on the desktop) is an aviation accident knowledge graph
built from NTSB, BEA, AAIB, TSB, ATSB and other final reports, with causal-path
search, a 3D FDR replay and a timeline builder. Data, pipeline and docs live in
[`blackbox/`](blackbox/README.md).
